# 🚀 Quick Start Guide

## Easiest Way to Run the Server (No Build Required!)

### Step 1: Start the Server
**Double-click `start-server.bat`**

That's it! The server will start automatically.

### Step 2: Test It (Optional)
**Double-click `test-message.bat`** to send a test message.

---

## What You Get

✅ **`start-server.bat`** - Starts the WhatsApp Bot Server  
✅ **`test-message.bat`** - Sends a test message to verify everything works

## First Time Setup

1. Make sure Node.js is installed (download from https://nodejs.org/)
2. Open a terminal in this folder and run:
   ```bash
   npm install
   ```
3. Create a `.env` file (see README.md for details)
4. Double-click `start-server.bat`

## Creating a Desktop Shortcut

1. Right-click `start-server.bat`
2. Select "Create shortcut"
3. Drag to desktop
4. Rename to "WhatsApp Bot Server"

Now you can start the server with one double-click!

---
